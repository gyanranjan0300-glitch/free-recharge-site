## How to Deploy

### GitHub Pages
1. Upload this folder to a GitHub repository
2. Go to Settings → Pages
3. Set source to `main` branch, `/ (root)` folder
4. Save — your site will be live!

### Vercel
1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Click Deploy — done!
